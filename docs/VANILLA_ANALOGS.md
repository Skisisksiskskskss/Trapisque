Read the relevant section before implementing (§5.2). Every class/path below was verified in the 26.3 sources or jar data on 2026-09-30.

## W1. Dimensions and dimension types
- **Where:** `world/level/dimension/DimensionType.java` (record + codec), `LevelStem.java`, `world/level/levelgen/WorldDimensions.java`, `resources/RegistryDataLoader.java` (`DIMENSION_REGISTRIES` = `Registries.LEVEL_STEM`, folder `dimension`). Data: `data/minecraft/dimension_type/{overworld,overworld_caves,the_nether,the_end}.json`; vanilla level stems live inside `worldgen/world_preset/normal.json`.
- **Pattern to copy:** a mod dimension = `data/thesift/dimension_type/<name>.json` + `data/thesift/dimension/<name>.json` (`{"type": …, "generator": {"type": "minecraft:noise", "settings": …, "biome_source": …}}`). `WorldDimensions.bake` unions datapack stems with the world's saved stems (datapack wins), so the dimension also appears in **existing** worlds. Level key `ResourceKey<Level>`; storage `dimensions/thesift/<name>/`.
- **DimensionType fields (26.3):** `has_fixed_time` (opt, false), `has_skylight`, `has_ceiling`, `has_ender_dragon_fight`, `coordinate_scale` (1e-5…3e7), `min_y`/`height`/`logical_height` (multiples of 16; height ≥16), `infiniburn` (block tag), `ambient_light`, `monster_spawn_light_level` (int provider 0–15), `monster_spawn_block_light_limit`, `skybox` (`none|overworld|end`, default overworld), `cardinal_light` (`default|nether`), **`attributes`** (environment attribute map, see W4), **`timelines`** (timeline tag/list), **`default_clock`** (world clock).
- **Gotchas:** sky/fog/cloud colours, music, ambient sounds, bed rules, respawn anchors, water evaporation, fast lava etc. are **no longer DimensionType fields** — they are environment attributes (W4). `/time` in a dimension acts on its `default_clock`. `DimensionType.getTeleportationScale(a,b)` = a.scale / b.scale (Nether ×8). `fabric-dimensions-v1` adds `DimensionEvents.MODIFY_ATTRIBUTES` and fail-soft loading of stems whose generator codec is missing (relevant to "mod removed", Phase 7).

## W2. Noise settings, density functions, material rules
- **Where:** `world/level/levelgen/NoiseGeneratorSettings.java`, `NoiseRouter.java`, `DensityFunctions.java`; data `worldgen/noise_settings/*.json` (overworld, nether, end, caves, floating_islands, amplified, large_biomes), `worldgen/density_function/{overworld,nether,end}/…`, `worldgen/noise/…`.
- **Noise settings keys (26.3):** `aquifers`, `debug_functions`, `default_block`, `default_fluid`, `disable_mob_generation`, `legacy_random_source`, `material_rule` (was `surface_rule`), `noise` (`min_y`, `height`, size factors), `noise_router` (`final_density`, `continents`, `erosion`, `depth`, `ridges`, `temperature`, `vegetation`, `chunk_surface_level`, …), `sea_level`, `spawn_target`.
- **New in 26.3:** material rules and material conditions are **registrable**: `worldgen/material_rule/*.json`, `worldgen/material_condition/*.json`; `material_rule` in noise settings can be a reference (`"minecraft:nether"`). Registrable `context_float_provider` / `context_int_provider` (number providers) and `worldgen/block_state_provider/*.json`.
- **Pattern to copy:** the Nether (`nether.json`: bounded height 128, `material_rule: "minecraft:nether"`, own density functions under `density_function/nether/`) for a self-contained dimension; the overworld router for continent/erosion-style terrain.
- **Forward-compat (26.4 snapshots, not our target):** `default_block` is removed (terrain blocks must come from material rules) and placed features must stay inside a 3×3-chunk domain. Design to both now.

## W3. Biomes and biome sources
- **Where:** `world/level/biome/Biome.java`, `MultiNoiseBiomeSource.java`, `worldgen/multi_noise_biome_source_parameter_list/{overworld,nether}.json`; data `worldgen/biome/*.json` (67 biomes).
- **Biome JSON (26.3):** `attributes` (environment attributes, incl. music/ambient sounds/sky/fog **and mob spawns**), `carvers`, `downfall`, `effects` (only colours: `water_color`, `grass_color`, `foliage_color`, `dry_foliage_color`), `features` (11 decoration steps of placed-feature ids), `has_precipitation`, `temperature`.
- **Spawning moved:** there is no `spawners` field; spawns are the attribute `minecraft:gameplay/natural_mob_spawns` = `{"modifier": "overlay", "argument": {"spawn_costs": {}, "spawns_by_category": {"monster": [{type, count, weight}], …}}}`. Structures override spawns with `spawn_overrides` (ancient city clears all categories).
- **Pattern to copy:** Nether multi-noise parameter list for a few distinct biomes; `deep_dark` for an underground biome with its own music.

## W4. Environment attributes, timelines and world clocks (the Tide candidate)
- **Where:** `world/attribute/` (`EnvironmentAttribute`, `EnvironmentAttributes` (all ids), `EnvironmentAttributeSystem`, `EnvironmentAttributeMap`, `AttributeTypes`, `modifier/*`, `WeatherAttributes`), `world/timeline/` (`Timeline`, `AttributeTrack`, `AttributeTrackSampler`), `world/clock/` (`WorldClock`, `ServerClockManager`, `ClockTimeMarker`), `server/commands/TimeCommand.java`. Data: `timeline/{day,moon,early_game,villager_schedule}.json`, `world_clock/{overworld,the_end}.json` (empty objects), `tags/timeline/{in_overworld,in_nether,in_end,universal}.json`.
- **Registries (all extensible by mods):** `BuiltInRegistries.ENVIRONMENT_ATTRIBUTE`, `BuiltInRegistries.ATTRIBUTE_TYPE`; datapack registries `timeline`, `world_clock`.
- **Attribute ids (26.3):** visual/{fog_color, fog_start_distance, fog_end_distance, sky_fog_end_distance, cloud_fog_end_distance, water_fog_color, water_fog_start_distance, water_fog_end_distance, sky_color, sunrise_sunset_color, cloud_color, cloud_height, sun_angle, moon_angle, star_angle, moon_phase, star_brightness, block_light_tint, sky_light_color, sky_light_factor, night_vision_color, ambient_light_color, default_dripstone_particle, ambient_particles}; audio/{background_music, music_volume, ambient_sounds, firefly_bush_sounds}; gameplay/{sky_light_level, can_start_raid, water_evaporates, bed_rule, straw_bed_rule, respawn_anchor_works, nether_portal_spawns_piglin, fast_lava, increased_fire_burnout, eyeblossom_open, turtle_egg_hatch_chance, piglins_zombify, snow_golem_melts, creaking_active, surface_slime_spawn_chance, cat_waking_up_gift_chance, bees_stay_in_hive, monsters_burn, can_pillager_patrol_spawn, natural_mob_spawns, creature_world_gen_spawn_probability, villager_activity, baby_villager_activity}.
- **Attribute flags:** `syncable` (sent to clients), `notPositional` (dimension-wide), `spatiallyInterpolated` (blends across biome borders), `fullResolutionBiomes` (block-exact biome lookup), `valueRange`.
- **Types & modifiers:** boolean (and/nand/or/nor/xor/xnor), tri_state, float & angle_degrees (alpha_blend/add/subtract/multiply/minimum/maximum), rgb_color & argb_color (alpha_blend/add/subtract/multiply/blend_to_gray), integer, moon_phase, activity, bed_rule, particle, ambient_particles (append, cross-fade), background_music, ambient_sounds, mob_spawn_settings (overlay: per-category replacement). Every type also supports `override`.
- **Layering (EnvironmentAttributeSystem):** attribute default → **dimension** `attributes` (constant) → **biome** `attributes` (positional; interpolated if flagged) → **timelines** listed in the dimension type's `timelines` (time-based, driven by clocks) → **weather** layers (if the level can have weather).
- **Timeline JSON:** `{"clock": <world_clock>, "period_ticks": N (opt), "time_markers": {id: {ticks, show_in_commands}}, "tracks": {<attribute>: {"modifier": op (default override), "ease": "constant" | {"cubic_bezier": […]} (opt), "keyframes": [{"ticks": t, "value": v}, …]}}}`. Non-interpolated types step between keyframes. Only syncable tracks are sent to clients.
- **Clocks:** `ServerClockManager` is server-wide **SavedData** (`world_clocks`); every registered clock has `totalTicks`, `partialTick`, `rate`, `paused`; ticks only while gamerule `advance_time` is on. API: `setTotalTicks`, `addTicks`, `setPaused`, `setRate`, `moveToTimeMarker`, `isAtTimeMarker`. Every change broadcasts `ClientboundSetTimePacket` and invalidates attribute caches in all levels. Timeline helpers: `getCurrentTicks(clockManager)`, `getPeriodCount`.
- **Commands for free:** `/time [of <clock>] set <ticks|time_marker>|add|pause|resume|rate <r>|query time|query <timeline> [repetition]`; plain `/time` uses the dimension's `default_clock`.
- **Reading from code:** `level.environmentAttributes().getValue(ATTR, pos)` (positional) / `.getDimensionValue(ATTR)`; e.g. `NaturalSpawner` reads `NATURAL_MOB_SPAWNS`, `Level` reads `SKY_LIGHT_LEVEL`, ice/sponge read `WATER_EVAPORATES`.
- **Implication:** a Tide cycle can be a `thesift:tides` world clock + a timeline on it (period = full cycle, time markers per Tide) that keyframes sky/fog/light/particles/music **and** `natural_mob_spawns` (overlay per Tide), with our own registered attributes for Sift-specific gameplay values; sync, interpolation, persistence and admin commands are vanilla's.
- **Gotchas:** clocks are global, not per-dimension (fine for a single Sift). `advance_time` off freezes Tides too. Time-marker ids must be unique per clock. `period_ticks` validation: markers/keyframes must lie in `[0, period)`.

## W5. Portals and teleport transitions
- **Where:** `world/level/block/Portal.java` (interface), `NetherPortalBlock`, `EndPortalBlock`, `EndGatewayBlock`, `world/entity/PortalProcessor.java`, `world/level/portal/{TeleportTransition,PortalForcer}.java`, `Entity#setAsInsidePortal / handlePortal / canUsePortal / getDimensionChangingDelay`.
- **Pattern:** portal block implements `Portal`; `entityInside` → `if (entity.canUsePortal(false)) entity.setAsInsidePortal(this, pos)`. `PortalProcessor` counts `portalTime` each tick inside; teleports when `portalTime >= getPortalTransitionTime(level, entity)` (Nether: gamerules `players_nether_portal_default_delay` = 80 / `players_nether_portal_creative_delay` = 0 for players, 0 for mobs; End: 0), decays by 4/tick when outside. Then `getPortalDestination(level, entity, entryPos)` returns a `TeleportTransition(newLevel, pos, velocity, yRot, xRot, relatives, postTeleport)`; stock callbacks `PLAY_PORTAL_SOUND`, `PLACE_PORTAL_TICKET` (`.then(...)` chains). `getLocalTransition()` → `CONFUSION` gives the Nether's wobble.
- **Arrival strategies:** End-style fixed arrival (`EndPlatformFeature.createEndPlatform`, spawn point) vs Nether-style paired portals (`PortalForcer.findClosestPortalPosition` via a POI type + `createPortal`). A paired custom portal needs its own POI type.
- **Gotchas:** portal cooldown `getDimensionChangingDelay()` (300 ticks non-players); returning from a dimension usually uses the player's respawn data (`findRespawnPositionAndUseSpawnBlock`); world border clamps exit positions (`newWorldBorder`).

## W6. Jigsaw structures (Ancient City, Trial Chambers)
- **Where:** data `worldgen/structure/ancient_city.json`, `worldgen/structure_set/ancient_cities.json`, `worldgen/template_pool/ancient_city/**`, `worldgen/processor_list/**`, templates `structure/ancient_city/**.nbt`.
- **Ancient City:** `type: jigsaw`, biomes `#minecraft:has_structure/ancient_city`, `start_pool: ancient_city/city_center` (3 variants), `start_jigsaw_name: minecraft:city_anchor`, `start_height: absolute -27`, `size: 7`, `max_distance_from_center: 116`, `terrain_adaptation: beard_box`, `spawn_overrides` clears every category; placement `random_spread` spacing 24 / separation 8 / salt 20083232.
- **The "portal" frame (measured from all 3 city_center templates):** one vertical plane of **reinforced deepslate, 22 wide × 8 tall, 20×6 opening**, 55 blocks + the top-centre **start jigsaw** (`city_anchor`, `final_state: reinforced_deepslate`) = 56 after generation. The opening is absent from the template (left open). The frame's top sits at the anchor, y = −27 → frame spans y −34…−27. Reinforced deepslate is unbreakable/unobtainable in survival, so every frame is a natural Ancient City centre.
- **26.3 NBT format:** structure palettes use `id` and `properties` (not `Name`/`Properties`).

## W7. Features and placement (26.3 format)
- **Where:** data `worldgen/feature/*.json` (235 files; was `configured_feature`), `worldgen/placed_feature/*.json`, `worldgen/block_state_provider/*.json`; code `world/level/levelgen/feature/…`, registry `BuiltInRegistries.FEATURE_TYPE` for new feature codecs.
- **Format:** configuration is inline (no `config` object); composite `minecraft:sequence` with per-step `placement`; block states `{"id": …, "properties": {…}}`; providers may be ids (`"minecraft:soil_beneath_tree"`). Placed feature = `{"feature": id, "placement": [count, in_square, height_range, biome, …]}`.
- **Pattern to copy:** `sculk_patch_deep_dark` (sculk patch + catalyst), `pale_oak_bonemeal` (tree with placers), `amethyst_geode`.
